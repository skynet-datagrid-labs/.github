# Support

## Where to ask

- Use the repository's issue forms for reproducible bugs, feature proposals, and bounded tasks.
- Use [organization Discussions](https://github.com/skynet-datagrid-labs/.github/discussions) for open-ended questions or project guidance that is not a defect report.
- Use pull requests to propose code, documentation, or data-pipeline changes. Link the related issue where one exists.
- For account access or team membership, contact an organization owner privately; do not post member details publicly.

## Security reports

Do not request help with a suspected vulnerability in a public issue or discussion. Use **Security → Report a vulnerability** in the affected repository. Private reporting is enabled on all four public organization repositories.

## Before requesting help

Include the repository, expected and observed behavior, relevant tool versions, safe reproduction steps, and the checks you have already run. Remove credentials, personal information, and restricted data from logs and examples.
