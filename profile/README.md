# Skynet Datagrid Labs

A student-led collaboration hub for data science, machine learning, analytics, and Python engineering. We build practical projects while learning reproducible, secure, and maintainable engineering practices.

## Current public portfolio

- [alpha-centauri-rescue](https://github.com/skynet-datagrid-labs/alpha-centauri-rescue) — team submission for Kaggle's Spaceship Titanic competition.
- [Kenya-Product-Sales](https://github.com/skynet-datagrid-labs/Kenya-Product-Sales) — Kenya FMCG sales KPI dashboard project.
- [sales-intelligence-dashboard](https://github.com/skynet-datagrid-labs/sales-intelligence-dashboard) — Power BI, Tableau, and Python dashboard assets.

## Contributing

Start with an issue, agree on scope and acceptance criteria, then open a focused pull request with evidence and documentation. Follow the [contribution guide](https://github.com/skynet-datagrid-labs/.github/blob/main/CONTRIBUTING.md) and [Code of Conduct](https://github.com/skynet-datagrid-labs/.github/blob/main/CODE_OF_CONDUCT.md). Do not submit secrets, personal data, or datasets without redistribution rights.
