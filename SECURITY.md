# Security policy

## Supported versions

Use the latest default-branch revision unless a repository documents supported releases.

## Reporting a vulnerability

Do not report vulnerabilities in public issues or discussions. Use the repository **Security → Report a vulnerability** flow. Private vulnerability reporting is enabled on all four public repositories: `alpha-centauri-rescue`, `Kenya-Product-Sales`, `sales-intelligence-dashboard`, and `.github`. Include only details needed to establish impact; do not attach unrelated secrets or personal data.

Organization maintainers should acknowledge the report, triage affected versions and severity, coordinate remediation and disclosure, and publish an advisory when safe. Response timing depends on maintainer availability; no response-time guarantee is made.

## Scope

This policy covers code and workflows maintained in repositories owned by `skynet-datagrid-labs`. Do not conduct destructive tests or access data/accounts without explicit authorization.
