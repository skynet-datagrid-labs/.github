# Security policy proposal

## Supported versions

Use the latest default-branch revision unless a repository documents supported releases.

## Reporting a vulnerability

Do not report vulnerabilities in public issues. Use the repository **Security → Report a vulnerability** flow when private vulnerability reporting is enabled. If unavailable, contact an organization owner through the organization page and request a private channel. Include only details needed to establish impact; do not attach secrets or personal data.

The response team should acknowledge within two business days when staffed, triage affected versions and severity, coordinate remediation and disclosure, and publish an advisory when safe. This is a proposed target, not a current service guarantee.

## Scope

This policy covers code and workflows maintained in repositories owned by `skynet-datagrid-labs`. Do not conduct destructive tests or access data/accounts without explicit authorization.
